## 📋 Project Description

**Social App** is a social media web application built with React and TypeScript.

The project provides an interactive interface for creating an account, sharing posts with text and images, commenting, liking, bookmarking, and managing your profile and settings.

The application communicates with a REST API to fetch and update real data, and keeps the interface in sync using React Query.

---

## ✨ Features

* 🔐 **Authentication** - Register and log in with form validation
* 🛡️ **Protected Routes** - Private pages are only accessible to logged-in users
* 📝 **Create Posts** - Share text posts with optional image upload
* 📰 **News Feed** - Browse posts from all users on the home page
* 🔍 **Post Details** - Open a single post with all its comments
* 💬 **Comments** - Add comments to any post
* ❤️ **Likes** - Like and unlike posts
* 🔖 **Bookmarks** - Save posts to view later
* ✏️ **Edit & Delete** - Manage your own posts
* 👤 **Profile** - View your profile and your posts
* 🔔 **Notifications** - See activity related to your account
* ⚙️ **Settings** - Change your password
* 🌐 **Offline Detection** - Notify the user when the connection is lost
* ⏳ **Loading States** - Skeleton loaders while fetching data
* ❌ **Error Handling** - Toast messages for API errors
* 🚫 **404 Page** - Friendly page for unknown routes
* 📱 **Responsive Interface** - Designed to work across different screen sizes

### Core Technologies

* **React 19** - UI components and state management
* **TypeScript** - Type safety across the whole project
* **Vite** - Fast development server and build tool
* **Tailwind CSS** - Utility-first styling and responsive layouts
* **React Router** - Client-side routing with protected routes
* **Context API** - Global authentication state

### Libraries

* **TanStack React Query** - Data fetching, caching, and mutations
* **Axios** - HTTP requests
* **React Hook Form + Zod** - Form handling and schema validation
* **React Hot Toast** - Toast notifications
* **React Icons** - Icon set
* **React Helmet** - Dynamic page titles
* **jwt-decode** - Reading the user id from the auth token
* **React Loader Spinner** - Loading indicators
* **react-use** - Network status detection

### API

* **Route Posts API** (`route-posts.routemisr.com`) - Authentication, posts, comments, likes, and bookmarks

## 🚀 Getting Started

### Installation

1. **Clone the repository**

```bash
git clone https://github.com/mahmoudAboElmagd005/Social-App.git
```

2. **Open the project folder**

```bash
cd Social-App
```

3. **Install dependencies**

```bash
npm install
```

4. **Run the development server**

```bash
npm run dev
```

5. **Build for production**

```bash
npm run build
```
